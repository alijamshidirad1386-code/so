# microblading.songul — Premium Mobile Site

نسخه‌ی استاتیک و موبایل‌محور سایت microblading.songul با HTML/CSS/JS خالص.

## ساختار

- `index.html`
- `assets/style.css`
- `assets/script.js`
- `assets/rose.svg` و `assets/petal.svg`
- `assets/images/` شامل لوگو و تصاویر محلی نمونه

## انتشار روی GitHub Pages

1. کل محتوای این پوشه را در ریشه‌ی Repository قرار بده.
2. از Settings → Pages، گزینه‌ی Deploy from branch را انتخاب کن.
3. branch اصلی و پوشه‌ی `/ (root)` را انتخاب کن.
4. بعد از انتشار، آدرس GitHub Pages با HTTPS ارائه می‌شود.

## نکته درباره تصاویر

تصاویر فعلی برای نمایش طراحی و استایل هستند و در متن سایت نیز به عنوان تصاویر مرجع معرفی شده‌اند؛ برای معرفی نمونه‌کار واقعی، آنها را با تصاویر واقعی کارهای خودت جایگزین کن و نام فایل‌ها را حفظ کن تا هیچ تغییر کدی لازم نباشد.

## امکانات تعاملی

- فیلتر چهار سبک
- جست‌وجوی مدل‌ها
- ذخیره مدل با LocalStorage
- مودال جزئیات مدل
- انتخاب مستقیم مدل برای فرم رزرو
- فرم رزرو با اعتبارسنجی پایه
- ذخیره درخواست رزرو روی دستگاه
- Share API / Clipboard fallback
- منوی موبایل
- انیمیشن‌های سبک و سازگار با reduced-motion

## امنیت

سایت هیچ اسکریپت خارجی، فونت خارجی، آنالیتیکس، iframe یا سرویس تبلیغاتی ندارد و برای صفحات استاتیک ساخته شده است. GitHub Pages را فقط با HTTPS منتشر کن. هشدار Google Safe Browsing می‌تواند به سابقه یا reputation دامنه/URL نیز مربوط باشد و چیزی نیست که صرفاً با HTML قابل تضمین یا کنترل باشد.
