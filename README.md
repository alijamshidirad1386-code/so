# Son Gool Hamed — Luxe UI package

این نسخه یک بازطراحی کامل و مستقل از UI قبلی است و گل رز/تزئینات رز از آن حذف شده‌اند.

## صفحات
- `index.html` صفحه اصلی
- `services.html` خدمات و FAQ
- `care.html` مراقبت بعد از کار + چک‌لیست تعاملی
- `booking.html` رزرو و ساخت متن درخواست
- `404.html` صفحه خطا

## فایل‌های اصلی
- `assets/style.css` سیستم طراحی و ریسپانسیو
- `assets/app.js` رفتارهای مشترک و امکانات تعاملی
- `assets/js/data.js` داده نمونه‌کارها
- `manifest.webmanifest` نصب‌پذیری پایه

تمام تصاویر محلی هستند و هیچ CDN/فونت/اسکریپت خارجی استفاده نشده است.
