# microblading.songul

سایت استاتیک، فارسی و RTL برای GitHub Pages.

## ویژگی‌ها
- بدون دیتابیس و بدون بک‌اند
- ۲۰ نمونه‌کار آماده با تصویر SVG محلی و توضیحات فارسی
- فیلتر نمونه‌کارها و نمایش تمام‌صفحه
- فرم رزرو با اعتبارسنجی و ذخیره در localStorage
- لینک اینستاگرام با آدرس `microblading.songul`
- طراحی موبایل‌محور و انیمیشن‌های سبک CSS
- مناسب GitHub Pages

## انتشار روی GitHub Pages
فایل‌ها را دقیقاً با همین ساختار در ریپازیتوری قرار بده و از Settings → Pages، شاخه اصلی و پوشه `/ (root)` را انتخاب کن.

## شخصی‌سازی مهم
برای تغییر متن‌ها، اطلاعات تماس یا اضافه‌کردن شماره واتساپ، `index.html` و `assets/script.js` را ویرایش کن.
